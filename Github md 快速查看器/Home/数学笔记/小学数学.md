## 1、认识数
#数学笔记

#### 1.1、实数
**实数(R)：** 包含所有数，分为无理数和有理数(**正有理数 Q+，负有理数 Q-**)

#### 1.2、有理数集
**有理数(Q)：** 能表示为分数形式的数，包括整数和分数
**整数(Z)：** 没有小数部分的数，包括正整数( *N+/N* )，0，负整数( *N-* )
**自然数(N)：** 非负整数，即 0, 1, 2, 3...

#### 1.3、数的分类
 - **∈（属于）** 元素与集合的关系。如果元素 **a** 在集合 **A** 里，记作 **a∈A**。例：2∈N（2属于自然数）

 - **⊆（子集）**：一个集合的所有元素都在另一个集合里，允许相等。例：{1,2}⊆{1,2,3}
 
 - **⊂（真子集）**：一个集合的所有元素都在另一个集合里，但不相等。例：{1,2}⊂{1,2,3}
 
 - **∉（不属于）**：元素不在集合中。例：4∉{1,2,3}

**数集关系：** N ⊂ Z ⊂ Q ⊂ R
 
**笔记：**
- 1、自然数比正整数多了一个 *”0“* ，*”0“* 也在自然数里面
- 2、*自然数*的表示符号：*N*
- 3、*有理数*指的是*有限或循环小数*（**注释：也包括正整数，负整数**）
- 4、*无理数*指的是*无限且不循环小数*【**注：根号也是无理数，根号一是有理数**】
- 5、不管是什么小数，都属于*分数*

## 2、四则运算

#### 2.1、加法
**交换律：**$$a + b = b + a$$ - 两个数相加，顺序可以互换
**结合律：**$$(a + b) + c = a + ( b + c )$$ - 三个数相加，先加前两个或后两个结果相同
**与减法的关系：**$$a - b = a + (- b)$$ - 减法可以看成加负数

**乘法相关公式：**
**完全平方和公式：**$$(a + b)^2 = a^2 + 2ab + b^2$$ - 两数和的平方展开
**完全平方差公式：**$$(a - b)^2 = a^2 - 2ab + b^2$$ - 两数差的平方展开
**平方差公式：**$$a^2 - b^2 = (a + b)(a - b)$$ - 两个平方数相减的因式分解

#### 2.2、乘法
**交换律：**$$a \times b = b \times a$$ - 两个数相乘，顺序可以互换
**结合律：**$$(a \times b ) \times c = a \times ( b \times c )$$ - 三个数相乘，先乘前两个或后两个结果相同
**分配律：**$$a \times (b + c) = a \times b + a \times c$$ - 一个数乘两个数的和，等于分别相乘再相加

**与除法的关系：**
$$a \times b = a \div \frac{1}{b}(b ≠ 0)$$ - 乘一个数等于除以它的倒数

#### 2.3、除法
$$a \div b = \frac{a}{b}$$
*解释：*$$4(被除数) \div 2(除数) = 2(商)$$ 
*重要规则：* 除数不能为0，即 b ≠ 0

**运算顺序：** 先乘除后加减，有括号先算括号里的
