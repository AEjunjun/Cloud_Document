#数学笔记 
## 拆单括号
#### 1、括号前有“+”号，去括号时不变号

列示：
```
a + ( b + c ) = a + b + c
```

#### 2、括号前是“-”号，所有符号都变相反号

列示：
```
a - (b - c + b) = a - b + c - d
``` 

#### 3、括号前或后有系数式字母时，每一项相相乘

列示：
```
a(b + c) = a * b + a * c
```

## 拆多层括号
#### 由内向外
```
	2 * [ x - 3( y - z )]
= 2 * [ x - ( 3y - 3z )]
= 2 * [ x - 3y + 3z ]
= 2x - 6y + 6z
```
