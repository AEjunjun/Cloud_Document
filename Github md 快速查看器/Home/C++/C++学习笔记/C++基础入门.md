#### 1.3 变量
**作用：** 给一段指定的内存空间起名，方便操作这段内存
**语法：** 数据类型  变量名 = 初始值;
**列示：**
``` C++
#include <iostream>
using namespace std;
int main()
{
	//变量的定义
	//语法：数据类型 变量名 = 初始值;
	int a = 10;
	cout << "a = " << a << endl;
	system("pause");
	return 0;
}
```
*变量存在的意义：方便我们管理内存空间*

**局部变量**
- 在函数或一个代码块内部声明的变量，称为局部变量。它们只能被函数内部或者代码块内部的语句使用。下面的实例使用了局部变量：
**实例：**
``` C++
#include <iostream>
using namespace std;
 
int main ()
{
  // 局部变量声明
  int a, b;
  int c;
 
  // 实际初始化
  a = 10;
  b = 20;
  c = a + b;
 
  cout << c;
 
  return 0;
}
```

**全局变量**
- 在所有函数外部定义的变量（通常是在程序的头部），称为全局变量。全局变量的值在程序的整个生命周期内都是有效的。
- 全局变量可以被任何函数访问。也就是说，全局变量一旦声明，在整个程序中都是可用的。下面的实例使用了全局变量和局部变量：
**实列：**
``` C++
#include <iostream>
using namespace std;
 
// 全局变量声明
int g;
 
int main ()
{
  // 局部变量声明
  int a, b;
 
  // 实际初始化
  a = 10;
  b = 20;
  g = a + b;
 
  cout << g;
 
  return 0;
}
```

#### 1.4 常量
**作用：** 用于记录程序中不可更改的数据
C++定义常量两种方式
1. define 宏常量 【# define 常量名 常量值】

2. const修饰的变量 【const 数据类型 常量名 = 常量值】
	- **通常在变量定义前加关键字const**，修饰该变量为常量，不可修改
**实列：**
``` C++

int main(){

	//day = 8; //报错，宏常量不可以修改
	
	//2、const修饰的变量
	const int month = 12;
	//month = 1; //报错，宏常量不可以修改
	system("pause");
	return 0;
}
```

## 3  运算符  
**作用**：用于执行代码运算
#### 3.1 运算运算符
**作用**：用于处理四则运算！
``` C++
#include <iostream>
using namespace std;
int main()
{
	int al = 3;
	int ba = 12;
	cout << al + ba << endl; // 加法 
	cout << al - ba << endl; // 减法 
	cout << al * ba << endl; // 乘法 
	cout << (float)al / ba << endl; // 除法
	  //小数位||| 【小数两位，不是四舍五入】  [double 双精度小数]
	  //在除法中，除数不允许为0
	  //在定义变量类型的的时候，是可以做小数的zwz
	  
	  
	
	int a2 = 10;
	int b2 = 3;
	
	cout << a2 % b2 << endl; //取模，解读 a2 %(除以并取余数);小数是不可以做取模运算xwx; 
	
	
	//这是其他运算
	 
	int a = a2--; 
	int b = ++b2;
		
	cout << a << endl;
	cout << b << endl; 
	
	system("pause");
	return 0;
}
```
a2++ 【后置递增】先输出a2再“+1”
++a2 【前置递增】先"+1"再输出a2
- 减法类似
- 这个操作只有加法与减法.

#### 3.2 赋值运算符
**作用**：用于将表达式的值赋给变量
``` C++
#include <iostream>
using namespace std;
int main()
{
	// =
	int a = 10;//把a定为10； 
	a = 100;//更改a定义为100; 
	cout << "a = " << a << endl;
	
	// +=
	a = 10;//把a定为10；
	a += 2;//加2！ 
	cout << "a = " << a << endl;
	
	// -=
	a = 10;
	a -= 2;//减2！
	cout << "a = " << a <<endl;
	
	// *=
	a = 10;
	a *= 4;//乘4！
	cout << "a = " << a << endl; 
	
	// /=
	a = 10;
	a /= 2;//除以二~~~
	cout << "a = " << a << endl;
	
	// %=
	a = 10;
	a %= 3;
	cout << "a = " << a << endl; 
	
	
	
	
	system("pause");
	return 0;
}
```
**总结**：先将计算，后赋予值

#### 3.4 逻辑运算符
**作用**：用于根据表达式的值返回真值或假值
``` C++
#include <iostream>
using namespace std;
int main(){
	
	//逻辑运算符 非 ! 
	int a =10;
	//在C++中 除了0 都为真 
	cout << !a << endl; 
	cout << !!a << endl;
	//非门 真为假，假为真 
	
	
	//逻辑运算符 与 &&
	//与门 当两个条件都为真，结果就为真
	a = 1;
	int b = 0;
	cout << (a && b) << endl;
	
	b = 1;
	cout << (a && b) << endl;
	
	//逻辑运算符 或 ||
	//或门 当两个条件其中一个为真，结果就为真
	cout << (a || b) << endl;
	
	a = 0;
	b = 0;
	cout << (a || b) << endl; 
	system("pause");
	return 0;
}
```

##### 4.1.2 三目运算符
**作用**：通过三目运算符实现简单的判断
**语法**：表达式1 ? 表达式2 : 表达式3
**解释**：
如果表达式1的值为真，执行表达式2，并返回表达式2的结果;
如果表达式1的值为假，执行表达式3，并返回表达式3的结果;
**实列**：
``` C++
int a,b,c;
cin>>a>>b
c = (a>b?a:b);//如果a>b为真输出a的值，反之输出b的值.
c = (a>b?a:b)=100;//将输出的变量赋值.
cout << c << endl;
```

#### 4.2 循环结构

##### 4.2.1 while循环语句
**作用**：满足循环条件，执行循环语句
**语法**：while(循环条件)(循环结构)
**解释**：只要循环条件的结构为真，就执行循环语句
**实列**：输出0~9这10个数
```
#include <iostream>
using namespace std;
int main()
{
	int a;
	a = 0;
	while(a<10)
	{
		cout << a << endl;
		++a;
	}
	return 0;
}
```
---
##### 4.2.2 do...while循环语句 
**作用**：满足循环条件，执行循环语句
**语法**：do{ 循环语句 } while { 循环条件 };
**注意**：与while的区别在于do...while会先执行一场循环语句，再判断循环条件
**实例**：输出0~9这10个数
```
#include <iostream>
using namespace std;

do
{
	cout << num << endl;
	num++;
}
while(num < 10);

return 0;
```
---
##### 4.2.3 for循环语句
**作用**：满足循环条件，执行循环语句
**语法**：for（起始表达式 ; 条件表达式 ; 末尾循环体){ 循环语句; }

**实列**：
```
int main()
{      运行前置;判断条件;执行语句
	for (i = 0; i < 10 ;i++)
	{
		cout << i << endl;
	}
	system("pause");
	return 0;
}
```

#### 4.3 跳转语句
##### 4.3.1 break语句
**作用**：用于跳出选择结构或者循环结构
break使用的时机：
- 出现在switch条件语句中，作用是终止case并跳出switch
- 出现在循环语句中，作用是跳出当前的循环语句
- 出现在嵌套循环中，跳出最近的内层循环语句
---
##### 4.3.2 continue语句
**作用**：在循环语句中，跳过本次循环中余下尚未执行的语句，继续执行下一次循环
**实列**：如果是奇数就输出，如果不是则不输出.
```
#include <iostream>
using namespace std;
int main()
{
	for (int i=0;i<=100;i++)
	{
		if(i % 2 == 0)
		{
			continue;
		}
		cout << i << endl;
	}
	return 0;
}

#### 6.3 函数的调用
**功能**：使用定义好的函数
**语法**：函数名（参数）
#### 6.4 值传递
- 所谓值传递，就是函数调用时实参将数值传给形参
- 值传递时，如果形参发生，并不会影响实参
人话：函数在调用你的数据时，不会改变你的数据，比如你定义了a=10，被函数调用了，你定的a=10不会因为含税调用而改变.
#### 6.5 函数的常见样式

常见函数样式有4种
1. 有参有反
2. 有参无返
3. 无参无返
4. 有参有返
要理解 C++ 中“函数的常见样式”，需从 **「参数有无」**​ 和 **「返回值有无」**​ 两个维度区分。你提到的“有参有饭”大概率是输入错误（推测应为「无参有返回」或「有参有返回」的笔误），下面先修正表述，再逐个解析四种典型函数的设计逻辑与用法：

##### 1. 有参有返回值的函数

- **核心特征**：函数**接收外部数据（参数）**，并**返回处理结果**。
    
- **语法结构**：
    ```
    返回值类型 函数名(参数列表) {  
        // 逻辑处理  
        return 结果; // 返回与“返回值类型”匹配的值  
    }
    ```
    
- **示例**：计算两数之和
- ```
    int add(int a, int b) { // 参数a、b（接收外部输入），返回值类型int（传出结果）  
        return a + b;       // 返回两数之和  
    }
    ```
    
- **应用场景**：数学运算（如加减乘除）、数据查询（如从数组中找最大值）、接口调用（如网络请求返回响应）等**需要“输入→处理→输出”完整流程**的场景。
    

##### 2. 有参无返回值的函数

- **核心特征**：函数**接收外部数据（参数）**，但**不返回任何结果**（返回值类型为 `void`）。
    
- **语法结构**：
    ```
    void 函数名(参数列表) {  
        // 逻辑处理（无return 带值语句，或用 return; 提前终止）  
    }
    ```
    
- **示例**：打印两个数的和（专注“操作”，而非“返回结果”）
    ```
    void printSum(int a, int b) { // 参数a、b（接收输入），无返回值（void）  
        cout << "和为：" << a + b << endl;  
        // 无需return 值，也可写 return; 提前结束函数  
    }
    ```
    
- **应用场景**：执行“副作用”操作（如打印日志、修改外部变量（通过引用/指针传参）、文件写入、硬件控制等）—— 这些操作**不需要把结果“传回”调用处**，只需“做完动作”即可。
    

##### 3. 无参无返回值的函数

- **核心特征**：函数**不接收外部数据（无参数）**，也**不返回结果**（返回值类型 `void`）。
    
- **语法结构**：
    ```
    void 函数名() {  
        // 逻辑处理（固定逻辑，无需外部输入）  
    }
    ```
    
- **示例**：程序启动时的欢迎语
    ```
    void greet() { // 无参数，无返回值  
        cout << "Hello, World!" << endl;  
    }
    ```
    
- **应用场景**：执行**无需外部输入的固定逻辑**，比如：程序初始化（加载默认配置）、定时任务（每隔一段时间检查状态）、固定提示（如游戏开始的“3,2,1 Go!”）等。
    

##### 4. 无参有返回值的函数

- **核心特征**：函数**不接收外部数据（无参数）**，但**返回一个结果**（返回值类型非 `void`）。
    
- **语法结构**：
    ```
    返回值类型 函数名() {  
        // 逻辑处理（生成/读取固定结果）  
        return 结果; // 返回与“返回值类型”匹配的值  
    }
    ```
    
- **示例**：封装固定时间的获取（简化演示，实际需结合时间库）
    ```
    string getCurrentTime() { // 无参数，返回string  
        // （伪代码：实际需调用系统时间API）  
        return "2024-01-01 12:00:00";  
    }
    ```
    
- **应用场景**：封装**“只读型”逻辑**，比如：读取配置文件的固定字段（无需外部传参）、生成固定种子（如随机数种子）、返回全局状态的快照等 —— 这些逻辑**不需要外部输入，但需要把计算/读取的结果“交出去”**。
    

##### 二维分类总结表

|函数类型|参数有无|返回值有无|设计逻辑|典型场景|
|---|---|---|---|---|
|有参有返回|✔️ 有|✔️ 有|输入→处理→输出|数学运算、数据查询|
|有参无返回|✔️ 有|❌ 无（void）|输入→执行操作|打印、修改外部变量（传引用）|
|无参无返回|❌ 无|❌ 无（void）|无输入→执行固定操作|欢迎语、初始化、定时任务|
|无参有返回|❌ 无|✔️ 有|无输入→生成/读取结果|封装固定配置、时间戳、全局状态|

##### 关键理解

- **“参数”**​ 决定函数是否需要**外部数据参与逻辑**；
    
- **“返回值”**​ 决定函数是否需要**把结果传回调用处**；
    

通过这两个维度的组合，C++ 能灵活封装不同粒度的逻辑：小到一行打印、大到复杂算法，都能通过“参数+返回值”的设计，让代码模块化、可复用性更强～

	//定义老师的元素
	L.id = 114514;
	L.name = "老马啊";
	L.age = 45;
	//定义学生的属性
	L.stu.id = 1145369;
	L.stu.name = "小马啊";
	L.stu.age = 12;
	
	cout << "***" << endl;//输出就不教惹！
}
```
**总结**：在结构体中可以定义另一个结构体作为成员，用来解决实际问题

#### 8.5 结构体做函数参数
**作用**：将结构体作为参数向函数中传递
传递方式又两种：
- 值传递
- 地址传递
列示：
```
#include <iostream>
#include <string>

using namespace std;
struct Add{
	//成员列表
	string name;
	int age;
	int score;
};
//1、值传递 - 可以函数更改数据，无法更改实参
void AddCout(struct Add s)
{
	cout << "名字：" << s.name << endl;
	cout << "年龄：" << s.age << endl;
	cout << "分数：" << s.score << endl;
}

//2、地址传递 - 可以更改实参
void AddCout1(struct Add * p)
{
	cout << "名字：" << p->name << endl;
	cout << "年龄：" << p->age << endl;
	cout << "分数：" << p->score << endl;
}

int main(){
	struct Add s;
	s.name = "你好";
	s.age = 18;
	s.score = 100;
	AddCout(s);
	AddCout1(&s);
	
	return 0;
}
```
**总结**：如果不想改变主函数中的数据，用值传递，反之用地址传递

#### 8.6 结构体中const使用场景
**作用**：用const来防止错误操作
实列：
```
#include <iostream>
using namespace std;

struct Add{
	//姓名
	string name;
	//年龄
	int age;
	//分数
	int score;
};
//将函数中的形参改为指针，可以减少内存空间，而且不会复制新的副本出来
void AddCout(const Add *s) <------设定只读
{
	s->age = 250; <--------无法更改
	cout << "名字：" << s->name << endl;
	cout << "年龄：" << s->age << endl;
	cout << "分数：" << s->score << endl;
}
int main(){
	//创建结构体变量
	struct Add s = { "张三" , 15 , 70 };
	
	//通过函数打印结构体变量信息
	AddCout(&s);
}
```

#### 8.8 结构体案例
##### 8.8.1 案例1
**案例描述**：
学生在做毕设项目，每名老师带领5个学生，总共有3名老师，需求如下
设计学生和老师的结构体，其中在老师的结构体中，有老师姓名和一个存放5名学生的数组作为成员，学生的成员有姓名、考试分数、创建数组存放3名老师，通过函数给每个老师及所带的学生赋值，最后打印出老师数据以及老师所带的学生数据
``` C++
#include <iostream>
#include <string>
using namespace std;
//创建学生的结构体
struct XueSheng {
	string Xname;//姓名
	int age;//年龄
	int FenShu;//分数
};
//创建老师的结构体
struct LaoShi {
	string Lname;
	struct XueSheng Xadd[5];
};

void LaoShiSpace(struct LaoShi Ladd[], int len)
{
	string nameSeed = "ABCDE";
	//给老师赋值
	for (int i = 0; i < len; i++)
	{
		Ladd[i].Lname = "老师";
		Ladd[i].Lname += nameSeed[i];

		//通过循环给每名老师所带的学生赋值
		for (int j = 0; j < 5; j++)
		{
			Ladd[i].Xadd[j].Xname = "学生";
			Ladd[i].Xadd[j].Xname += nameSeed[j];

			Ladd[i].Xadd[j].FenShu = 60;
			Ladd[i].Xadd[j].age = 15;
		}
	}
}

//打印所有信息
void CoutInfo(struct LaoShi Ladd[], int len)
{
	for (int i = 0; i < len; i++)
	{
		cout << "老师姓名：" << Ladd[i].Lname << endl;
		
		for (int j = 0; j < 5; j++)
		{
			cout << "学生名字：" << Ladd[i].Xadd[j].Xname << endl;
			cout << "学生分数：" << Ladd[i].Xadd[j].FenShu << endl;
			cout << "学生年龄：" << Ladd[i].Xadd[j].age << endl;
		}
	}
}
int main() {
	struct LaoShi Ladd[3];
	int len = sizeof(Ladd) / sizeof(Ladd[0]);
	LaoShiSpace(Ladd,len);
	CoutInfo(Ladd,len);
	return 0;
}
```
